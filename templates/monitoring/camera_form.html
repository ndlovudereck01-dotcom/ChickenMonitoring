Getting a good stream

Use an RTSP URL for IP cameras, e.g. rtsp://user:pass@192.168.1.20:554/stream1, or an HTTP snapshot stream. Credentials are stored in the database, so use a dedicated, read-only camera account.

Aim for a fixed, slightly elevated view of the floor with even lighting. Avoid pointing at bright windows — backlight makes birds hard to detect.

Tuning accuracy

Confidence
0.35–0.5
NMS IoU
0.45–0.6
Inference size
640 (CPU), 960+ (GPU)
Frame skip
2–4 on CPU
Min hits
5–8

Counting needs a few consistent detections before a track is registered, which filters out flicker. Raise min hits in dusty or low-light houses.

Geometry format

Coordinates are normalised to 0–1, with (0,0) at the top-left.

ROI:  [[0.10, 0.25], [0.90, 0.25], [0.90, 0.95], [0.10, 0.95]]
Line: [[0.00, 0.55], [1.00, 0.55]]

The easiest way to draw these is the live editor on the camera page.
